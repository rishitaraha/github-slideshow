# Map Assets

This folder contains assets such as fonts and sprites for the map.

## Map Fonts/Glyphs

Read about map fonts: [Mapbox Glyphs](https://docs.mapbox.com/style-spec/reference/glyphs/)

#### Fonts Available

- Open Sans Bold

### How to Convert a Custom Font to Map Fonts

1. Go to the [Maplibre Font Maker](https://maplibre.org/font-maker/).
2. Upload your fonts in `.ttf` or `.otf` format.
3. Download the compressed (zipped) output.
4. Extract your font files into this folder.
5. Use the static path to the folder in your style configuration.
